1服務內容

Mujica 是一款免費、非營利的個人開發 Discord 機器人，主要提供以下功能：

  • 自語音串流網站（透過 yt-dlp）播放音訊，支援排隊、跳過、暫停/繼續等基本播放控制。
  • 多種循環模式，包含單曲循環、隊列循環，以及依播放紀錄與 YouTube 資料 API 產生的推薦循環模式。
  • 每個伺服器獨立的音量與播放清單設定。
  • 播放紀錄查詢（歷史紀錄、個人/伺服器熱門歌曲統計）。
  • 以 MiniMax 語音合成 API 提供的 /tts 文字轉語音指令。

本服務目前公開邀請，任何 Discord 伺服器管理員皆可將 Mujica 加入其伺服器使用。

5資料蒐集與使用

為提供播放紀錄查詢與推薦功能，本服務會於自建之 SQLite 資料庫中，依「伺服器」與「使用者」範圍記錄下列資訊：

  • 播放過的歌曲標題與來源網址。
  • 點播的 Discord 使用者 ID、所屬伺服器 ID，以及播放時間戳記。

上述資料僅用於下列目的，不會出售、出租或用於本服務以外之商業行銷用途：

  • 顯示個人或伺服器的播放歷史與熱門歌曲統計（/history 相關指令）。
  • 依歷史紀錄產生個人化或伺服器層級的歌曲推薦。
不同伺服器的資料彼此獨立：所有查詢皆以伺服器 ID 區隔，不會出現跨伺服器的資料混用或外洩。

若您希望移除特定紀錄，可透過下方聯絡方式提出申請，開發者將協助自資料庫中刪除相關資料。

本服務為提供功能，會與下列第三方服務互動，該等服務各自受其自身條款與隱私權政策規範：

  • YouTube / yt-dlp 支援之串流網站：用於解析與播放音訊來源。
  • YouTube Data API：用於在歷史紀錄不足時，輔助產生歌曲推薦。
  • MiniMax 語音合成 API：使用 /tts 指令時，您輸入的文字內容會傳送至 MiniMax 以產生語音，請避免輸入您不希望傳送給第三方服務之敏感內容。
