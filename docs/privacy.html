1我們蒐集的資料

為提供播放紀錄與推薦功能，本服務會在開發者自行管理的 SQLite 資料庫中，永久保存下列資料：

資料內容來源
歌曲資訊歌曲標題、來源網址、長度使用者點播的內容
播放紀錄Discord 使用者 ID、伺服器 ID、播放時間使用者使用播放指令時

另外，本服務會在記憶體中暫存各伺服器的播放佇列、音量、循環模式與設定，這些資料只在程式運作期間存在，機器人重新啟動後即消失。

2資料使用目的

  • 顯示您個人或伺服器的播放歷史與熱門歌曲統計。
  • 依您或伺服器的播放紀錄，產生歌曲推薦。
  • 維持機器人的基本運作與除錯。
資料依伺服器隔離：所有查詢皆以伺服器 ID 限定範圍，不會在不同伺服器之間交叉使用或顯示。

3我們不蒐集的資料

  • 不記錄或保存您在頻道中的一般訊息內容。
  • 不錄製、不保存語音頻道中的任何語音。
  • 不蒐集您的真實姓名、電子郵件、電話、位置或付款資訊。

機器人僅會處理您明確使用的斜線指令與播放器按鈕所帶來的資訊。

4第三方服務與資料傳輸

為提供功能，下列情況會將資料傳送給第三方，該等服務各自受其隱私權政策規範：

  • Discord：機器人透過 Discord 平台運作，使用者 ID 與伺服器 ID 由 Discord 提供。
  • YouTube 及其他串流網站（透過 yt-dlp）：為解析並播放音訊，機器人會向這些網站發出請求，請求內容為您提供的連結或搜尋關鍵字。
  • YouTube Data API：推薦功能在歷史紀錄不足時，會以歌曲標題作為關鍵字向該 API 查詢。
  • MiniMax 語音合成 API：使用 /tts 指令時，您輸入的文字會傳送給 MiniMax 以產生語音。生成的音檔僅以暫存檔形式用於播放，播放後即刪除。請勿輸入敏感個人資訊。

5資料保存與安全

播放紀錄儲存於開發者管理的伺服器上，除非您提出刪除請求，否則會持續保存以維持歷史與推薦功能。開發者採取合理措施保護資料，但網路傳輸與儲存無法保證絕對安全。

6資料分享

我們不會出售、出租或交易您的資料，也不會將其用於廣告。除第 4 節所述功能所需的第三方傳輸，以及法律要求依法揭露的情況外，不會與他人分享。

另外請注意，「播放歷史」等指令的結果可能顯示在頻道中，同一伺服器的其他成員可能因此看到您點播過的歌曲。

7您的權利與刪除請求

您可以隨時透過下方聯絡方式，請求：

  • 查詢與您 Discord 使用者 ID 相關的資料。
  • 刪除與您相關的播放紀錄。

請於信件中提供您的 Discord 使用者 ID（於 Discord 開啟開發者模式後，可對自己的頭像按右鍵複製），開發者會盡速處理。您也可以隨時把機器人踢出伺服器並停止使用本服務。

8兒少隱私

本服務依附於 Discord 平台，使用者須符合 Discord 規定的最低年齡。我們不會刻意蒐集未達該年齡者的資料；若發現此類情況，將依請求刪除相關資料。

9政策變更

本政策可能不定期修訂，更新後將於本頁面公布並立即生效。您於更新後繼續使用本服務，即視為同意修訂內容。
